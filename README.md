## what's on it

a landing page, then three stops: **about**, **projects**, and **skills**.

- **about** is where the personality lives: a bio, a photo/video archive, and a scroll through the anime, shows, and fits i'm into
- **projects** lays my work out like a pinboard of polaroids, tech-stack chips and all
- **skills** is a flip-through spellbook of everything i work with, because a normal list felt too boring for a portfolio
- scroll to the bottom of any page and the footer becomes a little interactive sea: drag the ship to sail it, click the water for a splash, click the ship to fire the cannon
- light/dark mode, a little sound design, and custom pixel cursors run underneath all of it

## built with

- **react 19** + **typescript**, components, typed data/content
- **vite** for the dev server and build
- **react router** for client-side routing between pages
- hand-rolled **css** for the pixel-art theme and light/dark mode, no ui framework
- `simple-icons` for tech/brand icons used across projects and skills
